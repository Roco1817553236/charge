# 全应用红入绿出配色设计

日期：2026-08-24

## 目标

按照中文环境常见的“红涨绿跌”认知，把账页所有收支金额语义统一为：收入红色、支出绿色。正结余和结余增加使用收入红，负结余和结余减少使用支出绿。

## 全局颜色令牌

新增独立的 `--income-color` 与 `--expense-color`，同时提供明暗主题颜色。不得复用 `--danger` 作为收入色：删除、报错和破坏性操作继续使用警示红，并通过图标和文字识别。

紫色 `--accent` 继续用于导航、焦点和普通主操作；分类自定义颜色及统计图扇区颜色不改变。

## 应用范围

### 记账页

- 支出选中态、金额输入和“保存支出”按钮使用支出绿。
- 收入选中态、金额输入和“保存收入”按钮使用收入红。
- 未选择和禁用状态保持中性色。

### 流水页

- 每笔支出金额使用绿色，并保留减号。
- 每笔收入金额使用红色，并保留加号。
- 每日小计中的“支出”和“收入”分别使用对应颜色。
- 删除按钮仍使用警示红，不与收入金额共用令牌。

### 统计页

- 当前收入、正结余使用收入红；当前支出、负结余使用支出绿。
- 收入增加和结余增加用红；收入减少和结余减少用绿。
- 支出增加用绿；支出减少用红。
- 支出大类/小类图的扇区维持分类色，但所有支出金额文字使用支出绿。

### 物品页

物品总投入、总日均、单件总成本、日均成本、购买价以及维修/配件金额都属于成本，统一使用支出绿。分类图标颜色、紫色新增按钮和错误提示不改变。

## 可访问性

所有金额继续保留“收入/支出/结余”文字、正负号及上下文，不以颜色作为唯一信息。明暗主题下收入红和支出绿都必须与所在背景保持可读对比，焦点样式仍使用紫色。

## 数据影响

本次只修改 CSS 令牌、组件类名和展示样式，不修改流水、分类、物品、IndexedDB 或 JSON 备份格式。

## 测试

- 组件测试断言记账类型切换、流水金额、统计正负值和物品成本使用正确语义类。
- 安全样式测试断言收入/支出令牌存在于明暗主题，警示色仍独立。
- 端到端测试在支出与收入流程中读取最终计算样式，验证红入绿出。
- 360px、414px 和桌面宽度下金额不得截断或溢出。
