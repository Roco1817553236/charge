# 账页本地存储与 JSON 备份设计

## 目标

账页改为完全本地运行的个人记账 PWA，不再提供 Microsoft 登录或 OneDrive 同步。每个浏览器用户配置继续使用独立的 IndexedDB 账本；用户通过 JSON 文件在 Windows、Android 和浏览器之间手动迁移数据。

本次变更必须保留现有流水、分类、统计偏好和旧版 JSON 备份的兼容性。升级应用不能清空、重建或自动合并用户账本。

## 用户界面

- 右上角入口从同步状态胶囊改为普通设置按钮，不再显示“待同步”“已同步”或云端状态。
- 设置面板标题改为“设置与备份”。
- 删除 OneDrive 客户端 ID、Microsoft 登录、同步密码、信任设备、恢复密钥确认、云端快照和同步冲突界面。
- 保留应用更新、迁移救援备份和 JSON 备份功能。
- 保留加密 JSON 导出。用户设置至少 10 个字符的备份密码后，应用下载加密 JSON 和独立恢复密钥。
- 保留明文 JSON 导出，并继续要求二次确认。
- JSON 导入同时接受加密 JSON 和受支持的旧版明文 JSON；加密文件可使用备份密码或恢复密钥解锁。
- 删除 CSV 导出，让备份区域只呈现 JSON 工作流。
- 页脚改为“本地保存 · 加密备份 · 无广告与分析追踪”。

## 运行时与依赖删除

删除以下可执行能力：

- Microsoft MSAL 身份验证；
- OneDrive App Folder 网络读写；
- 同步引擎、ETag 重试和远端合并；
- 在线、页面恢复和定时触发的后台同步；
- 云端快照读取与恢复；
- 可信设备同步密钥存取；
- OneDrive 冲突选择与同步状态管理入口。

删除 `@azure/msal-browser` 依赖、Microsoft 客户端 ID 环境变量以及 OneDrive 专用源文件和测试。生产包中不得再包含 Microsoft 登录或 Graph 请求代码。

## 本地数据与兼容性

现有 IndexedDB 数据库和账本快照结构保持兼容。流水及分类中的修订字段、设备记录、历史冲突字段和旧同步元数据可作为惰性兼容数据保留，因为删除这些字段需要高风险数据库迁移，并会破坏旧版备份的往返导入。

这些兼容字段不会再触发网络请求、后台任务或用户界面状态。旧版遗留的 OneDrive 文件不会被应用自动删除或修改；更新后的应用不会再访问它们。

加密模块只保留 JSON 备份所需的 AES-256-GCM 创建和解锁能力。云端信封更新、可信会话和远端指纹等同步专用接口应删除。

## 网络与安全

- 内容安全策略删除 Microsoft 登录、Microsoft Graph 和 OneDrive 下载域名，仅允许应用自身所需资源。
- 应用不新增服务器、账号系统、分析追踪或遥测。
- GitHub Pages 只分发静态应用文件，不接收账本内容。
- 加密 JSON 的密码和恢复密钥只在当前设备处理。
- 不自动删除浏览器中可能遗留的旧 Microsoft 登录缓存，以免误删同源下无法可靠归属的凭据；移除运行时代码后这些缓存不再被读取。

## 文档与版本

- README 改写为本地存储、多人数据隔离、JSON 备份和跨设备手动迁移说明。
- 删除 README 中 Entra 注册、Microsoft Graph 权限、OneDrive 使用和同步故障说明。
- PWA 清单描述改为本地记账与加密 JSON 备份。
- `.env.example` 删除 Microsoft 客户端 ID，只保留应用版本。
- CHANGELOG 增加 v1.3.0，明确 OneDrive 和 CSV 已移除，JSON 备份保留。
- 生成 v1.3.0 源代码包、可部署网页包和 GitHub 更新说明。

## 测试与验收

- 设置组件测试验证只显示 JSON 备份、导入与应用更新，不出现 OneDrive、Microsoft、同步或 CSV 操作。
- 应用组件测试验证右上角设置入口及本地保存文案，不启动后台同步。
- 安全测试验证 CSP 不包含 Microsoft、Graph 或 OneDrive 域名，依赖清单不包含 MSAL。
- 备份服务测试继续覆盖加密 JSON、明文 JSON、密码/恢复密钥解锁、格式校验和文件大小限制。
- 旧版本 JSON 快照导入后，流水、分类和统计设置保持一致。
- 全量单元测试、类型检查、生产构建、Playwright 浏览器测试、覆盖率和依赖安全扫描全部通过。
- 在桌面和窄屏移动视口检查设置与备份面板，确认无溢出或遗留云同步文案。

## 不在本次范围内

- 自动局域网同步、WebDAV 或其他云盘同步；
- 用户账号和服务器端数据存储；
- 自动清理旧 OneDrive 云端文件；
- 破坏旧 JSON 格式的数据库简化；
- 从 JSON 以外的格式导入或导出。
