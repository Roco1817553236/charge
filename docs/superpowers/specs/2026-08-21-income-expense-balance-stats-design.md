# 统计页恢复收入与结余设计

日期：2026-08-21

## 目标

统计页恢复收入、支出和结余，同时保留现有的大类/小类支出去向和流水展开，不恢复每日收支趋势、十二个月趋势或其他占空间图表。

## 页面结构

页面标题改为“收支统计”。月份/年度切换、期间前后切换和当前月比较口径保持不变。

期间选择区下方依次显示：

1. 当前期间三张汇总卡：收入、支出、结余。
2. 三项同期变化：收入变化、支出变化、结余变化。
3. 原有“支出去向”大类环形图。
4. 原有选中大类的小类环形图及流水明细。

移动端三张卡允许换行或紧凑排列，但金额和正负号不得截断。收入使用正向颜色，支出保持主色，结余根据正负使用正向或警示颜色。

## 统计口径

- `结余 = 收入 - 支出`。
- `收入变化 = 本期收入 - 上期收入`。
- `支出变化 = 本期支出 - 上期支出`。
- `结余变化 = 本期结余 - 上期结余`。
- 收入和支出变化同时显示绝对金额与变化率；上期为 0 时显示“上期无收入”或“上期无支出”，不显示无穷百分比。
- 结余变化只显示绝对金额，避免上期结余为负或跨正负时产生误导性百分比。

月度当前月份继续支持“本月至今/上月同期”和“完整月份”两种口径；过去月份使用完整月。年度当前年份使用今年至今/去年同期；过去年份使用完整年。收入、支出、结余和下方支出分类必须使用完全相同的日期边界。

## 数据与架构

扩展现有 `ExpensePeriodReport` 和 `ExpensePeriodComparison`，在同一次期间过滤中同时聚合收入、支出、结余及收入/支出笔数。支出分类图继续只消费支出记录。

本功能只改纯统计和展示，不修改 IndexedDB、流水、分类、JSON schema 或备份格式。

## 空数据

- 没有任何流水时，收入、支出、结余均显示 ¥0.00，同期变化显示 ¥0.00。
- 只有收入时仍显示三张汇总卡；下方支出去向显示现有“暂无支出数据”空状态。
- 只有支出时收入显示 ¥0.00，结余显示负值，支出去向正常展示。

## 测试

- 领域测试覆盖月度/年度收入、支出、结余、笔数、绝对变化和上期为 0。
- 组件测试覆盖只有收入、只有支出、正负结余、月度/年度切换和完整月份口径。
- 原有大类、小类图表和流水明细测试继续通过。
- 端到端测试新增一笔收入和一笔支出，验证统计页三项汇总与结余。
