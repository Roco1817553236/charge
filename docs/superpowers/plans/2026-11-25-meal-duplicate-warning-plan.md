# 餐次重复提醒实施计划

设计依据：`docs/superpowers/specs/2026-11-25-meal-duplicate-warning-design.md`

## 目标版本

v1.9.0。复用现有重复确认弹窗，增加同日餐次检测，不改变数据结构。

## 实施顺序

### 1. 领域规则

- 先扩展 quickEntry 领域测试，覆盖餐次归一化、同日匹配、别名、删除、收入、其他大类、编辑排除和集合去重。
- 实现纯函数并保持现有金额重复函数兼容。

### 2. Store 预检结果

- 先扩展 bookStore 测试，定义包含候选、金额命中数、餐次名称和餐次命中数的预检结果。
- 修改 `previewDuplicateEntry`，解析分类并合并两类候选。
- 无有效金额时仍不进行保存预检，让现有金额校验负责报错。

### 3. 弹窗摘要与交互

- 先扩展 App 测试，覆盖仅餐次、双重命中、返回保留和确认只保存一次。
- 修改 App 的弹窗状态和文案，候选列表及焦点管理保持不变。

### 4. 端到端、版本与文档

- Playwright 验证同日不同金额早餐触发、返回不保存、确认后保存。
- 更新 package、环境示例、README、CHANGELOG 和设置页到 v1.9.0。

### 5. 审查与发布

- 运行完整测试、类型检查、构建、端到端、覆盖率和依赖审计。
- 独立代码审查后修复所有 Critical/Important。
- 推送、合并 PR、等待 Pages 部署并核对线上资源。

## 约束

- 每项生产行为先有失败测试。
- 只提醒，不自动删除、合并或禁止保存。
- 不修改历史数据、数据库和 JSON。
