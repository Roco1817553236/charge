# 账页

账页是一款完全本地运行的个人记账 PWA，可安装到 Windows、Android，也能直接在浏览器中使用。它不需要账号、自建服务器或付费服务：流水、分类和设置都保存在当前浏览器的 IndexedDB 中，跨设备时通过 JSON 备份文件手动迁移。

## 已实现功能

- 快速记录支出和收入，金额按“分”精确保存
- 记账、流水、统计、物品四个页面可横向滑动，也可使用底部导航切换
- 两级分类；大类和二级分类均可新建、改名、更换图标/颜色、排序、置顶和归档
- 新建账本的餐饮默认小类为早餐、正餐、晚餐、零食饮料；已有账本不会被自动改名
- 流水搜索、按月份/收支/大类/二级分类筛选，支持编辑、复制、软删除和撤销
- 月度环比和年度同比；支出大类与小类同屏显示金额及占比，小类使用稳定的高区分度配色
- 点击统计小类，可在当前页面展开对应月份或年度的全部流水
- 独立物品分类与日均成本：购买价格叠加维修费、配件费后，从购买日期起按天实时平摊
- 物品可从已有支出流水创建或手动添加；停用后冻结使用天数和日均成本
- 完全离线可用，可安装为 Windows/Android 应用
- 加密 JSON 与明文 JSON 导入导出
- 应用内检查并应用 PWA 更新，更新不会清空本地账本

## 数据保存与多人使用

GitHub Pages 只负责发送静态网页文件，不接收账单。应用没有服务器、用户账号、广告、分析追踪或遥测。

每份账本由“网站地址 + 浏览器用户配置”隔离：

- 不同手机、不同电脑之间的数据互不影响。
- 同一台电脑使用不同的 Chrome/Edge 用户配置时，数据互不影响。
- 同一台电脑、同一浏览器用户配置访问同一个账页地址时，会使用同一份本地账本。
- 无痕模式中的数据可能在关闭窗口后被删除，不适合长期记账。
- 清除网站数据或浏览器存储可能删除账本，因此必须定期导出备份。

把已发布的网址发给别人即可共同使用这款应用，但每个人仍然拥有自己的本地账本。

## JSON 备份与跨设备迁移

### 推荐：加密 JSON

1. 打开右上角“设置与备份”。
2. 点击“加密 JSON 备份”。
3. 输入至少 10 个字符的备份密码。
4. 应用会下载加密 JSON 文件和独立恢复密钥文件。
5. 将加密 JSON 传到另一台设备，在“导入 JSON 备份”中选择文件。
6. 输入原备份密码，或选择“恢复密钥”并粘贴恢复密钥后导入。

备份密码和恢复密钥任意保留一个即可解锁文件，但建议分开、安全保存。两者都丢失后，加密 JSON 无法恢复。

### 明文 JSON

明文 JSON 无需密码，便于迁移或自行处理，但其中包含完整金额、分类和备注。应用会在下载前再次确认，请勿把明文文件发送给无关人员。

### 导入行为

导入会在确认后用备份内容替换当前设备的本地账本，不会自动合并两边的数据。操作前建议先把目标设备当前账本也导出一份备份。密码错误、文件损坏、结构不合法或文件超过安全大小限制时，当前账本不会被修改。

物品、独立物品分类、维修费和配件费都会随 JSON 一起备份。旧版本生成的受支持 JSON 仍可导入，导入后物品列表为空并自动创建默认物品分类；原流水、记账分类和设置保持不变。分类名称会按备份原样保留，因此包含“外卖”“晚餐”或自定义名称的备份都能兼容。数据库升级自检失败时，设置页还会显示“下载迁移救援备份”，便于保住升级前的本地数据。

## 物品日均成本

进入底部“物品”页后，可以查看总投入、当前总日均、物品数量和最高/最低日均。点击物品卡片会在当前页面展开购买价格、维修费和配件费，不需要进入并返回详情页。

- 购买日期就是日均成本起算日，当天购买按 1 天计算，不需要再填写开始使用日期。
- 日均成本 =（购买价格 + 维修费 + 配件费）÷ 从购买日起累计的天数。
- 从支出流水创建物品或追加成本时只建立来源引用，不会修改或重复生成原流水。
- 停用物品会以停用日期冻结使用天数；恢复使用后继续从原开始日期计天。
- 物品分类独立于记账分类，可新增、归档和恢复。

## 本机开发运行

需要 Node.js 22.12 或更高版本。

```powershell
npm ci
Copy-Item .env.example .env.local
npm run dev
```

打开终端显示的本地地址即可。`.env.local` 只需按需设置应用版本，不需要任何第三方客户端 ID 或密钥。

完整校验：

```powershell
npm test
npm run typecheck
npm run build
npm run test:e2e
npm run test:coverage
```

## 免费发布到 GitHub Pages

仓库已包含 `.github/workflows/deploy.yml`。将代码上传到 GitHub 后：

1. 在仓库 `Settings → Pages` 中选择 GitHub Actions 作为来源。
2. 推送到 `main` 或 `master`。
3. 工作流会先运行测试和生产构建，再发布 `dist/`。
4. `Actions` 中的 `Test and deploy Pages` 全部变绿后即可访问 Pages 地址。

不需要配置 Secrets、Variables、数据库或服务器。

发布新版本后，已安装的 PWA 会在后台下载更新。“设置与备份”会显示可用更新，用户点击应用即可，不需要卸载重装。存在未保存草稿或编辑中的流水时会阻止刷新，必须先保存或清空。

## 安装到设备

- Windows：使用 Edge 或 Chrome 打开已发布的 HTTPS 地址，点击地址栏的“安装应用”。
- Android：使用 Chrome 打开同一地址，在菜单中选择“安装应用”或“添加到主屏幕”。
- 浏览器：直接访问即可；同一浏览器用户配置中的数据会持续保留。

卸载应用、清除网站数据或更换浏览器前，请先导出加密 JSON 备份。应用更新通常不会删除 IndexedDB 数据，但备份仍是抵御误操作和设备故障的唯一可靠方式。

## 安全实现

- 密钥派生：PBKDF2-HMAC-SHA-256，默认 600,000 次迭代
- 内容加密：AES-256-GCM，每个密文块使用独立随机 IV
- 密钥恢复：随机恢复密钥独立包裹数据密钥
- 完整性保护：账本正文的认证数据绑定恢复密钥封装，密文或封装被替换后解锁会失败
- 输入校验：严格验证 JSON 账本结构、算法参数、盐、IV、密文大小和 KDF 上限
- 文件限制：导入文件最大 16 MiB，加密正文设有独立大小上限
- 网络权限：内容安全策略只允许应用自身所需资源，不开放第三方账号或云盘接口
- 数据模型：流水软删除和分类墓碑保留修订信息，确保旧备份可以安全往返导入

这是一款个人工具，不替代专业财务、税务或审计系统。请自行定期备份并妥善保存备份密码或恢复密钥。
